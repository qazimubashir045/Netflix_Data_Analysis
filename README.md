# Netflix_Data_Analysis
# 📺 Netflix Data Analysis Project

This project is a comprehensive exploratory data analysis (EDA) of Netflix's content catalog. It aims to uncover insights about the type of content offered by Netflix, trends over time, content ratings, and geographical production patterns using Python libraries like Pandas and Matplotlib.

---

## 🔍 Key Objectives

- Understand the distribution of Movies vs TV Shows
- Explore the growth of Netflix content over the years
- Analyze the most common content ratings
- Identify the top countries producing content for Netflix
- Visualize all insights using clean, meaningful charts

---

## 📊 Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
